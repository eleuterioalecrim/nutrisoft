# Guia para Usuário Final

## O que é o NutriSoft?

O NutriSoft é uma aplicação local para apoio à gestão nutricional, permitindo:

- Cadastro de pacientes.
- Registro de anamnese.
- Registro de recordatório habitual.
- Avaliação antropométrica.
- Registro de exames laboratoriais.
- Comparação dos exames com referências cadastradas.
- Dashboard visual.

## Como abrir

Use um dos arquivos:

```text
INICIAR_NUTRISOFT_WINDOWS.bat
INICIAR_NUTRISOFT_LINUX.sh
```

## Onde ficam os dados?

Os dados ficam na pasta:

```text
data/
```

## Onde ficam os gráficos?

Os gráficos gerados ficam na pasta:

```text
reports/charts/
```

## O sistema precisa de internet?

Depois de instalado, o uso normal é local.
A internet pode ser necessária apenas para instalar dependências Python.

## Cuidados

O sistema não substitui avaliação profissional.
Ele apenas organiza dados e aponta comparações com referências cadastradas.
