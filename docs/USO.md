# Guia de Uso do NutriSoft

## Fluxo recomendado

1. Cadastrar paciente.
2. Cadastrar anamnese.
3. Cadastrar recordatório habitual.
4. Cadastrar avaliação antropométrica.
5. Cadastrar exames laboratoriais.
6. Cadastrar referências de exames, se necessário.
7. Cadastrar aliases para padronizar nomes de exames, se necessário.
8. Executar análise comparativa.
9. Consultar dashboard do paciente.

## Pacientes

Use a página **Pacientes** para cadastrar, listar e buscar pacientes.

## Anamnese

Use a página **Anamnese** para registrar informações clínico-nutricionais e recordatório habitual.

## Antropometria

Use a página **Antropometria** para registrar peso, altura e circunferência da cintura.
O sistema calcula o IMC automaticamente.

## Exames

Use a página **Exames** para cadastrar exames laboratoriais, referências e aliases.

## Dashboard

Use a página **Dashboard** para consultar indicadores gerais e a visão individual do paciente.

## Bases CSV

Use a página **Bases CSV** para visualizar os arquivos locais usados pelo sistema.
