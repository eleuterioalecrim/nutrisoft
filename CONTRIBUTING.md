# Contribuindo com o NutriSoft

## Padrão de desenvolvimento

- Mantenha a lógica de negócio em `src/`.
- Mantenha componentes visuais em `src/web/`.
- Não misture dados reais de pacientes com código.
- Use `data_examples/` para dados fictícios.
- Atualize o `CHANGELOG.md` a cada nova versão.

## Commits sugeridos

```bash
git add .
git commit -m "Descrição objetiva da alteração"
git push
```

## Segurança

Nunca envie dados reais de pacientes para repositórios públicos.
